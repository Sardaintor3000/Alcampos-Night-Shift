// ==================================================================
//
//  Cómo escribir:
//   - Cada versión empieza con una línea que empieza por "## ", por ejemplo:
//       ## Versión 1.6 · 17 de octubre
//   - Debajo, cada novedad en su propia línea empezando por "- ", por ejemplo:
//       - Los zombis normales son más rápidos.
//   - Si quieres una palabra en negrita, escríbela **así**.
//   - Pon lo más nuevo arriba del todo.
//   - Las líneas que empiezan por // (como estas) no se ven en el juego.
//
//  La ventana sale sola la primera vez que alguien abre el juego después
//  de que cambies la versión de arriba del todo. Los jugadores pueden
//  volver a verla con el botón "Novedades" de la pantalla de inicio.
//
//  Escribe debajo de esta línea:
// ==================================================================

//  ## Version 1.6
//     -Larisa Update
//        *Caballo Wally y poco mas
